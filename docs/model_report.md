# Model and evaluation report

This report describes the checked-in model artifacts and their saved holdout evaluations. It does not report learning outcomes.

## Classical exercise classifiers

The saved report is `models/evaluation_report.json`. Both classifiers were trained using `data/processed/exercises_augmented.csv` (1,344 rows), with deterministic 22% random test splits (`random_state=42`).

| Task | Test rows | Accuracy | Macro-F1 | Inputs |
| --- | ---: | ---: | ---: | --- |
| Structured difficulty | 296 | 0.922297 | 0.831212 | Metadata, engineered numeric indicators, topic, known domain, and source type |
| Text domain | 279 | 0.982079 | 0.974313 | Romanian problem text |

The structured model is a preprocessing pipeline with median imputation/scaling, categorical imputation/one-hot encoding, and a `RandomForestClassifier`. Inputs include `Itemul`, `Sursa_year`, problem/solution/answer lengths, digit and symbol counts, indicators for mathematical constructs, and categorical `Tema_norm`, `Domeniu`, and `Sursa_type`. The known topic/domain and source metadata are part of the features; this is not a text-only difficulty model.

The domain model combines word/character TF-IDF with `ComplementNB`. It predicts a bank domain; it does not generate an explanation or rank recommendations.

Reproduce the saved holdout predictions without fitting a model:

```bash
python tools/verify_saved_models.py
```

The saved report and joblib artifacts are treated as preserved inputs. Classification reports are not rewritten to match stale plots. Run `python tools/refresh_figures.py` to rebuild current figures from the saved report and the current filtered practice bank.

### Evaluation limits

The split is random by row, not grouped by source or template family. Related generated templates can occur across train and test, so scores may be optimistic for genuinely new problem families. There is no independent external dataset evaluation. The difficulty labels are existing dataset labels, not independently measured learner difficulty. The domain and difficulty scores are classification measurements only; they are not evidence of educational benefit or real-student learning gains.

## Optional neural interaction classifier

`data/processed/student_interactions.csv` has 2,200 synthetic interactions; the saved report `models/neural_student_state_report.json` records a 440-row test split with accuracy 0.922727 and macro-F1 0.914048. The target states and inputs are generated by repository rules, not collected from actual learners. These figures measure reproduction of synthetic rule-generated labels only.

TensorFlow is optional and is not installed by the default lightweight requirements. The application uses neural inference only if TensorFlow and all saved model artifacts exist. Startup and tests never train this model automatically. To intentionally train it during development, use:

```bash
python src/neural_student_state_model.py
```

That operation writes model artifacts and is not part of demo startup, package validation, or the lightweight verification path. A NumPy reproduction of weights is not considered a TensorFlow runtime test.

Saved outputs in `docs/exercises_augmented_integration.ipynb` are historical. The notebook was not rerun; any data-building or training work should be performed on a separate copy of the repository and its artifacts.

## Tutoring logic boundaries

Answer checking compares normalized exact text and supported exact rational scalars; labels and units must match. It does not convert units, execute expressions, or prove general symbolic equivalence. Hints/reflection questions are stored or predefined. Mastery and next-exercise choice are rule-based and approximate, not calibrated probability or a learned ranking model. Reflection responses are not analyzed.
